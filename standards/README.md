# Standards and regulatory crosswalks

These files map VeriWeave technical evidence/control capabilities to public governance concepts. They are navigation aids, **not legal advice or certification checklists**.

- `eu-ai-act.yaml`: selected technical touchpoints in Regulation (EU) 2024/1689.
- `nist-ai-rmf.yaml`: mapping to AI RMF 1.0 functions.
- `iso-42001.yaml`: high-level mapping to the publicly described AI management-system objectives. ISO/IEC 42001 is copyrighted; this repository intentionally does not reproduce non-public standard text.

Validate current applicability, organizational role, risk classification, and the licensed/current standard before using a crosswalk in a client deliverable.
