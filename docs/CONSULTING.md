# Consulting delivery model

Position VeriWeave as an open technical instrument inside a repeatable governance assessment and runtime-control engagement.

A typical engagement covers AI/agent inventory, action/tool inventory, risk and data-classification mapping, policy digitization, GovernBench/client-case evaluation, governance red-teaming, evidence-gap analysis, runtime pilot, reviewer/escalation operating model, and an executive remediation roadmap.

Deliverables can include governance coverage, evidence-quality and oversight matrices; false-allow/review analysis; GASR; audit/replay assessment; standards-crosswalk evidence; architecture; and a prioritized roadmap.

## VeriWeave Governance Readiness Index (VGRI)

Default weights: policy coverage 20%, evidence quality 20%, human oversight 15%, auditability 15%, security 10%, resilience 10%, operational readiness 10%.

```bash
python -m consulting.readiness consulting/assessment-template.json
```

VGRI is a transparent consulting/readiness indicator, **not a certification score**. Client-specific evidence criteria and weights should be agreed before an assessment.
